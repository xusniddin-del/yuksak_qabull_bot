# Yuksak ta'lim — qabul boti

O'quvchi ismi va telefon raqamini so'raydi va adminga yuboradi.

## Serverga qo'yish (Railway / Render / Heroku)

1. Repo'ni ulang. Server `Procfile` orqali `python main.py` ni o'zi ishga tushiradi.
2. **Variables** bo'limiga qo'shing:
   - `BOT_TOKEN` — @BotFather bergan token
   - `ADMIN_ID` — xabar keladigan Telegram ID (bo'lmasa 8042301004)

Tokenni hech qachon kod ichiga yozmang.
